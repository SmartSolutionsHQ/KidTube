Add it to your home screen

It opens full screen like an app, with the family's own icon.

It's on this device already. You're using the app now.

Phones only install it from a secure (HTTPS) address. Until the family's box has one, it works in the phone's browser. The install guide shows how to add HTTPS.

On this device

Your browser can add it straight away.

iPhone or iPad

  1. Open this page in Safari.
  2. Tap the Share button, the square with an arrow pointing up.
  3. Scroll down and tap Add to Home Screen, then Add.

The home-screen app keeps its own sign-in, separate from Safari. Sign in once more the first time you open it.

Android

  1. Open this page in Chrome.
  2. Tap the menu, the three dots at the top right.
  3. Tap Install app or Add to Home screen.

A computer

In Chrome or Edge, use the install icon at the right end of the address bar. Other browsers keep it as a bookmark, which works just as well.
